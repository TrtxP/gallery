# Gallery — a virtual exhibition of the past month

A 3D gallery built in Blender and displayed in the browser with Three.js / React Three Fiber.
Designed for a **touchscreen kiosk with no mouse or keyboard**: visitors can move between artworks with swipes, arrows, or dots.

**Stack:** Vite 8 · React 19 · TypeScript (strict) · three 0.182 · @react-three/fiber 9 · @react-three/drei 10

## Getting started

Node.js 20 or newer and [Git LFS](https://git-lfs.com/) are required. The gallery models, artwork, and audio are stored with Git LFS.

Install Git LFS, then initialize it before cloning the repository:

```bash
git lfs install
git clone https://gitea.kood.tech/illyacherepanov/gallery.git
cd gallery
```

If you already cloned the repository before installing Git LFS, run `git lfs install` and then `git lfs pull` inside the project directory to download the files.

Start the project from the `gallery` directory:

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production build in dist/
npm run preview    # preview the production build
npm run lint
```

For kiosk use, open the built site in fullscreen mode, for example: `chrome --kiosk http://localhost:4173`.

## How to use

1. **Enter Exhibition** — the camera smoothly enters the gallery and the music starts.
2. Move to the next or previous artwork with a **swipe left or right**, the large side arrows, or the dots at the bottom. The ← and → keys also work for development convenience.
3. **Overview** — return to the overall view of the gallery.
4. **Music on/off** — toggle the music; your choice is remembered.

After the last artwork, moving forward returns to the first. Moving backward from the first returns to the last.

## Project structure

```text
blender/
  build_gallery.py      the complete Blender project in one script (room, lighting, models, baking, export)
  assets/models/        downloaded models (armchair, horse head, ceramic vase); assets/artworks/ contains the paintings
  build/                generated output: gallery.glb, gallery.json, gallery.blend
public/
  models/gallery.glb    scene used by the site (compressed with meshopt + WebP)
  audio/ambient.mp3     ambient music
src/
  gallery/              3D scene: Room (GLB), SkyDome, CameraRig, cameraPath (routes), data
  ui/                   interface: Intro, Tour, music, swipes, ErrorBoundary
  bonus/                optional features (disabled by default)
  data/gallery.json     viewpoints and artwork descriptions (generated by the Blender script)
scripts/
  sync-from-blender.mjs copies and compresses the Blender scene for the site
```

## Updating the scene from Blender

```bash
# 1. Build the scene (see blender/README_blender.md for details and flags)
blender --background --python blender/build_gallery.py -- --out blender/build
# 2. Copy it into the site (compress the GLB and copy gallery.json)
npm run sync:blender
```

Edit artwork titles, artists, and years in the `ARTWORKS` list in `blender/build_gallery.py`. Place your own paintings in `blender/assets/artworks/art_01.jpg … art_06.jpg`.
For full-resolution textures, run Blender without `--quick` and use `--res-scale 1.0`. Bake time depends on the resolution, samples, and available hardware.

## Requirements checklist

| Requirement | Implementation |
| --- | --- |
| Blender scene: room with walls, ceiling, and floor at realistic proportions | `build_gallery.py`: room 10 × 14 × 4 m, 6 m window, partition; eye level 1.6 m, paintings at 1.55 m |
| Lighting and textures | Window daylight, ceiling fill, and track spots for the paintings and display objects. Procedural materials include oak flooring, plaster, and stone |
| External 3D models | Poly Haven's [Modern Arm Chair 01](https://polyhaven.com/a/modern_arm_chair_01) by Vibrant Nordic, [Horse Head](https://polyhaven.com/a/horse_head) by Tina, and [Antique Ceramic Vase 01](https://polyhaven.com/a/antique_ceramic_vase_01) by James Ray Cock (CC0) |
| Custom models | Wooden chair with tapered legs and a slatted back, stone plinth, and beveled vase pedestal |
| Export and display through Three.js | `public/models/gallery.glb` → `src/gallery/Room.tsx` (React Three Fiber) |
| Navigation without a mouse or keyboard | Swipes, arrows, dots, and the Overview button; buttons are at least 44 px |
| Model optimization | The supplied models retain their original geometry. The GLB uses dedicated baked textures, meshopt geometry compression, and WebP images |
| No console errors or warnings | Checked in Chromium on desktop and in touch mode: the console is clear |
| Baking | Blender maps highlights with AgX and bakes diffuse lighting and material detail. Dedicated textures for the imported models also capture the glossy response. The exported glTF materials are unlit |
| Music toggle | `src/ui/useAmbientMusic.ts`, with a Music on/off button; playback starts on the first touch, fades in and out, and pauses when the tab is hidden |
| Realism, smoothness, and clarity | The camera goes around the partition instead of through it. On portrait screens it moves back so the entire painting fits, and it respects `prefers-reduced-motion` |
| Bonuses separate from the core experience | `src/bonus/`; enabled only with a flag (see below) |

## Performance

- The room export contains 12 mesh primitives and about 34.5k triangles.
- **On-demand rendering** (`frameloop="demand"`): the GPU is idle while a visitor views a painting; frames are rendered only during transitions.
- The welcome screen preloads the compressed GLB. Music starts when the visitor enters the exhibition.
- Transitions take the same amount of time on any hardware: their duration is based on elapsed time, not frame count.

## Bonus features

Disabled by default; they do not affect the core experience. Enable them with `http://localhost:5173/?bonus=autotour,kiosk,stats` or the `VITE_BONUS` environment variable at build time.

| Flag | What it does |
| --- | --- |
| `autotour` | Adds an **Auto tour** button that advances through artworks every 7 seconds |
| `kiosk` | Returns to the start screen after 90 seconds without touch input (for public displays) |
| `stats` | Shows draw calls, triangles, and textures in the corner |

## Notes

- `three` is pinned to **0.182.0**: R3F 9.8 still uses `THREE.Clock`, which produces a console warning starting with r183. The pin can be removed once R3F switches to `THREE.Timer`.
- The music was generated in code as an original composition. Replace it with your own file at `public/audio/ambient.mp3`.
- The paintings in `blender/assets/artworks/` are currently placeholders (generated abstract images). You can replace them without changing the code.
